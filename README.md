# 에스파크 라운딩 (개인용 웹앱)

남한강에스파크CC 27홀(피크·아쿠아·키네틱)용 개인 GPS 거리·스코어 웹앱. 로그인 없음, 기록은 각 휴대폰에만 저장.

## 기능
- 홀 그림(골프장 홈페이지 코스공략 레이아웃, OB·페널티 표시 포함) 위에 내 GPS 위치 표시
- 그린 중앙(또는 지정한 핀)까지 남은 거리, 그린 앞/뒤 근사 거리
- 내 클럽 거리 기준 추천 클럽 + 공략 동선(티샷 → 세컨드 → 그린)
- 샷 기록 버튼(위치 저장, 샷 거리 계산), 퍼트 +/-, 홀인/OK → 이글·버디·파·보기 자동 판정, 누적 스코어
- 하단 시트를 쓸어 올려 홀 선택(번호·PAR·거리·미니맵), 스코어카드, 설정
- 그린 그림을 누르면 핀 위치 지정, 그린 경사도 이미지 보기

## 배포
정적 파일만 있으면 됩니다(HTTPS 필수 – 위치 권한 때문). GitHub Pages: Settings → Pages → Branch `main` / `(root)` → Save.

## 집에서 미리 보기
주소 뒤에 `?sim=1`을 붙이면 지도를 눌러 내 위치를 가상으로 옮길 수 있습니다.

## 데이터
- `data.js`: 홀별 PAR·HDCP·5개 티 거리·공략 문구(홈페이지), 그린/티 GPS 좌표(위성사진 대조), 그림 기준점(그린 중심·백티·100/150/200m 아크·페어웨이 중심선)
- 좌표 신뢰도 `conf`: high(위성사진 대조 확인) / mid(대체로 일치) / low(추정, A1~A3)
- 홀 그림·그린 이미지는 골프장 홈페이지 주소를 그대로 불러오며 이 저장소에는 포함하지 않습니다.
